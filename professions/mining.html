Professions

Mining

Pickaxe-based ore gathering from the currently installed VORP Mining resource.

Tool

Pickaxe required

The mining resource expects the inventory item pickaxe. Mining is started with the configured SPACE prompt and a rock can take up to three swings. Tool durability and a configurable break roll are part of the loop.

Yield

Chance-based materials

Mining rewards are selected from a configured item table with chance rolls. The current configuration includes a gold-nugget reward entry among the possible materials, making mining distinct from—but economically related to—the dedicated river gold-panning system.

Town restriction entries keep extraction behavior out of inappropriate settlement areas. The mining resource also maintains its own cooldown and difficulty settings, so repeated work is not intended to be an instant spam interaction.
